科学上网的方法

1. 使用VPN（虚拟专用网络）

VPN是最常见的科学上网工具之一，它通过在公共互联网和用户设备之间建立一个加密的虚拟专用网络，实现对网络流量的加密和转发，进而突破网络封锁。

使用VPN的步骤：

  • 下载VPN应用：在App Store中下载您选择的VPN客户端，如ExpressVPN、NordVPN等。

  • 注册与登录：打开应用，按照提示进行注册并登录。

  • 选择服务器：选择一个位于允许访问B站内容的国家或地区的VPN服务器，例如美国或日本。

  • 开启VPN连接：成功连接后，您的设备将通过该服务器访问互联网，实现科学上网。

2. 使用代理服务器

代理服务器是一种通过中介服务器转发用户请求的方式，通过这种方式，用户可以伪装自己的IP地址，达到绕过地域限制的目的。常见的代理协议有HTTP和SOCKS代理。

使用代理的步骤：

  • 进入iOS设备的网络设置：在iOS设备的“设置”中找到“Wi-Fi”选项，点击当前连接的网络。

  • 配置代理：在网络配置页面，找到“HTTP代理”选项，选择“手动”并输入代理服务器的地址和端口号。

  • 保存设置并连接网络：完成代理设置后，重新连接Wi-Fi，您就可以通过代理服务器访问互联网。

3. 使用网络工具（如Shadowrocket/Surge）

对于一些有经验的用户，使用像Shadowrocket、Surge等网络工具是一个更为灵活的选择。这些应用允许用户导入配置文件，进行更为个性化的科学上网设置。

使用Shadowrocket的步骤：

  • 购买应用并安装：首先，您需要在App Store购买并安装Shadowrocket。

FAQ

Mihomo 的 Rule-Set 与 Clash Premium 是否兼容？
Mihomo 完全兼容 Clash Premium 的 Rule-Set 格式，支持相同的远程规则订阅与策略分组。用户可直接迁移原 Clash 配置，无需额外修改或转换。
Mellow TUN 模式与 SOCKS5 代理有什么区别？
TUN 模式拦截系统 IP 层流量，实现全局代理；SOCKS5 代理通常只影响指定应用。TUN 更适合全局加速，如游戏、视频和浏览器流量，提高网络稳定性和覆盖范围。
如何在 Windows 上安装 Clash for Windows？
在 Windows 上安装 Clash for Windows 十分简单。只需前往官方 GitHub 页面下载最新版安装包，运行安装程序后导入订阅链接或配置文件即可。安装完成后，用户可以通过图形化界面方便地切换节点、编辑规则和控制代理模式。
VLESS 的伪装流量如何提升隐蔽性？
VLESS 通过 Reality 或 XTLS 模式对流量进行伪装，使其在外观上与正常 HTTPS 请求一致。这样可以绕过深度包检测和封锁，提高高封锁网络环境下的可用性。
如何配置 Sing-box 使用 DoH 加密 DNS？
在 dns 模块中添加类型为 doh 的上游，如 `https://1.1.1.1/dns-query`，并指定 bootstrap 地址。启用加密 DNS 可防止 DNS 泄露并加快国际解析速度，提高整体隐私保护。
Matsuri 的节点测速结果能影响策略组吗？
可以。Matsuri 会将延迟最低的节点自动标记为优先节点，结合策略组，程序会优先选择最佳节点处理流量，保证访问速度和连接稳定性。
Nekobox 是否支持跨客户端节点管理？
支持。Nekobox 可以独立管理 Shadowsocks、Clash 等客户端节点，互不干扰。结合策略组，可实现多客户端流量分流和网络优化，提高节点管理效率和使用便利性。
PassWall2 如何结合延迟选择最优节点？
PassWall2 定期测速节点延迟，并结合策略组自动选择延迟最低的节点。无需手动操作即可保证网页、视频和游戏流量快速稳定访问，提高整体网络体验。
VLESS + XTLS 在移动网络的优势？
XTLS 模式减少握手次数和加密开销，适合高延迟或不稳定的移动网络。结合策略组和多节点切换，可提升网页浏览、视频播放和游戏的连接稳定性和流畅度。
V2Ray QUIC 模式在高丢包网络中的优势？
QUIC 基于 UDP 协议，支持多路复用和零握手，可减少延迟和丢包。适合视频、游戏和即时通讯等高丢包环境，保证访问稳定性和速度，提高整体体验。
